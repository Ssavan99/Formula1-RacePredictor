Method

Walk-forward. For each of the 103 races in 2022–2026, every model is fitted only on races dated strictly before it, then asked to predict that one race.

Leak guard. Every column is registered with the point in time at which it becomes knowable; unregistered columns are rejected rather than admitted. It exists because the original pipeline fed the finishing status of the race being predicted into the model — worth +0.136 top-1 on its own.

Where the headroom is. 88% of winners start in the top three, so the real task is telling front-runners apart, not finding one driver in twenty.

Data: Jolpica-F1, weather from Open-Meteo, practice pace from FastF1. All free, no API keys.

Predictions are committed to git before each race runs — the commit history is the receipt.
