Method

Walk-forward. For each of the 103 races in 2022–2026, every model is fitted only on races dated strictly before it, then asked to predict that one race.

Leak guard. Every column is registered with the point in time at which it becomes knowable; unregistered columns are rejected rather than admitted. It exists because the original pipeline fed the finishing status of the race being predicted into the model.

Where the headroom is. 88% of winners start in the top three, so the real task is discriminating between front-runners, not finding a winner among twenty.

Data. Jolpica-F1 (successor to Ergast, shut down early 2025), weather from Open-Meteo, practice pace from FastF1. All free, no API keys.

Why the record is trustworthy. Predictions are committed to git before the race runs, so commit history is the evidence nothing was fitted after the fact.

Honest limitation. Backtest weather is reanalysis — what actually happened during the race — while a live prediction has only a forecast. Figures involving weather are an upper bound on live performance.
